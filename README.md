## Level-set Joint Inversion Software
* Joint inversion of seismic full-waveform and vertical gravity acceleration data to reconstruct the wave-velocity function and density distribution of target anomalies, generating intuitive visual images.
* Applies the acoustic wave equation to model seismic wave data and integral equations to characterize gravity acceleration anomalies.
* Employs the level-set method to represent interface structures and achieves effective multi-physics data fusion by characterizing the structural similarity between velocity and density parameters.
## Download & Usage
* Please download the software package and test datasets from the **Releases** page.
* After extracting the software package, click the .exe file to launch the application. Detailed instructions can be accessed via 'Help' at the top of the panel.
* The test datasets include three examples: the rock model, the salt dome model, and the circular demonstration model. Recommended YAML parameters for each case can be found in config.yaml, and recommended control panel settings are provided in panel_configuration.pdf.

## 水平集联合反演软件
* 通过地震波全波形数据、垂直方向的重力加速度数据联合反演目标异常体的波速函数和密度分布，形成直观图像。
* 运用声波方程刻画地震波数据、积分方程刻画重力加速度异常值。
* 采用水平集方法表示界面结构，通过界面刻画速度和密度参数的结构相似性，实现多物理数据的有效融合。
